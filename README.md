# ✈️ Flight Intelligence Dashboard

A lightweight, real-time web application built with **HTML5, Tailwind CSS, and Google AI Studio (Gemini 2.5 Flash)**. This application allows users to enter any flight number to retrieve departure and arrival airport details, exact geographical coordinates (Latitude & Longitude), local operational times, and automatic conversion into **Indian Standard Time (IST)** via Google Search Grounding.

---

## 🌟 Key Features

* **Real-Time Data Retrieval:** Leverages Gemini 2.5 Flash with live Google Search grounding to fetch operational flight info without hardcoded data.
* **Dual-Timezone Support:** Displays scheduled arrival times in both the destination local timezone and converted **Indian Standard Time (IST)**.
* **Precision Coordinates:** Provides exact Latitude and Longitude for both departure and arrival airports.
* **Modern Dashboard UI:** Built with Tailwind CSS for high contrast, rapid readability, and mobile responsiveness.
* **Single-File Architecture:** Fully contained inside a single `index.html` file—no complex builds, node modules, or server setup required.
